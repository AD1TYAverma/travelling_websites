# Wanderlust - Travel & Tourism Website

A modern, responsive, and visually appealing Travel & Tourism Website built using HTML5, CSS3, Bootstrap 5, and JavaScript.

Wanderlust helps users discover destinations, explore travel packages, browse galleries, and submit booking inquiries through an elegant and user-friendly interface.

---

## Features

- Modern Premium UI/UX
- Fully Responsive Design
- Dark Mode / Light Mode Toggle
- Animated Hero Section
- Sticky Navigation Bar
- Smooth Scrolling
- Interactive Destination Cards
- Tour Packages Section
- Travel Gallery
- Booking Form
- Contact Form
- Glassmorphism Design Elements
- Bootstrap 5 Components
- Mobile Friendly Layout
- SEO Friendly Structure
- Clean and Reusable Code
